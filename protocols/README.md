# Network Protocols 🌐

Implementation examples and deep-dives into various network protocols.

## Protocols Covered

### Application Layer
- **HTTP/HTTPS** - Web protocols and secure communications
- **DNS** - Domain Name System resolution
- **FTP/SFTP** - File transfer protocols
- **SMTP/POP3/IMAP** - Email protocols

### Transport Layer
- **TCP** - Transmission Control Protocol
- **UDP** - User Datagram Protocol
- **WebSocket** - Real-time communication

### Network Layer
- **IP** - Internet Protocol (IPv4/IPv6)
- **ICMP** - Internet Control Message Protocol
- **Routing Protocols** - OSPF, BGP, RIP

### Data Link & Physical
- **Ethernet** - Frame structure and operations
- **Wi-Fi** - Wireless networking protocols
